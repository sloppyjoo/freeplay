FreePlay Installer

Version 0.1 beta, for the Polyend Play+ and the original Play with an RT processor.

This is beta firmware. It will have bugs. Back up your SD card first, and don't install it right before a gig. FreePlay is unofficial and isn't supported by Polyend. You can go back to the official firmware at any time.

It won't work on every original Play. Original Plays with a K66 processor aren't supported yet. The guide explains how to tell which one you have.

1. Download the official firmware

Get it from polyend.com. It has to be exactly this version:

  1. Play+: 1.3.0 (PlayPlus_v1.3.0.ppf)
  2. Original Play: 1.6.0 (PolyendPlay_v1.6.0.ppf)

2. Drop it here

Your file stays on your computer. Everything happens in this browser tab, and nothing is uploaded.

3. Copy both files to your SD card

  1. Back up your SD card, if you haven't already.
  2. Copy the new FreePlay file and the official firmware file into the card's Firmware folder. The official file is your way back.
  3. Keep the file name as it is. The device only lists firmware files with the right name.
  4. Eject the card properly before you pull it out.

4. Flash it

  1. Put the card in your device and turn it on.
  2. Go to Settings → Firmware → Update Firmware.
  3. Pick the FreePlay file and confirm.
  4. The screen shows Updating firmware, please do not power off for about 30 seconds. Don't turn it off or pull the card out. It restarts by itself when it's finished.

To go back, flash the official file the same way. If something goes wrong, see Going back to the official firmware.
